# 订单服务配置说明

本文档描述订单服务的整体配置。文档由三段不同格式的内容组成，
**每一段都用代码块围栏包裹，围栏语言标出了这一段的格式**。
你需要按格式把它们拆开，分别转换后作为本节点的输出交付。

## 第一部分：服务概述（Markdown）

```markdown
# 订单服务

订单服务负责接收、校验与分派订单，是整个交付平台的入口。

## 职责

- 接收外部系统提交的订单
- 校验必填字段与业务规则
- 按区域与负载分派给处理队列

## 依赖

- 用户中心：校验下单人身份
- 库存服务：预占库存
- 消息队列：异步通知下游
```

## 第三部分：分派规则（YAML）

```yaml
dispatch:
  strategy: weighted-round-robin
  regions:
    - name: cn-east
      weight: 60
      queues:
        - order-east-1
        - order-east-2
    - name: cn-south
      weight: 40
      queues:
        - order-south-1
  fallback:
    queue: order-dead-letter
    alertAfterSeconds: 300
  limits:
    maxPerQueue: 500
    cooldownSeconds: 10
```

## 交付要求

按上面三段各自的格式，分别产出三份独立文件：

1. Markdown 段 → 一份 Markdown 文档；
2. JSON 段 → 一份 JSON 文档；
3. YAML 段 → 一份 **Properties** 文档（不是 YAML）。

Properties 采用简单扁平化规则，按本节点技能里写明的方式转换。
